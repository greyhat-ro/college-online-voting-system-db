# CampusVote — College Online Voting System

Portfolio-ready MCA final-year project for a web-based college election platform.

## Stack
- HTML5 / CSS3 / JavaScript
- GitHub Pages
- Supabase Auth + PostgreSQL for production
- Responsive UI

## Demo
Student: `student@demo.local` / `Demo@123`
Admin: `admin@demo.local` / `Admin@123`

## Features
- Student voting interface
- Admin election dashboard
- Candidate management view
- Election lifecycle concept
- One-vote-per-position database constraint
- Results dashboard
- Audit-log schema
- Responsive design
- GitHub Pages deployment

## Important
The included frontend is a static portfolio demo. Do not use the localStorage voting workflow for a real election. A production deployment needs a secure backend, strict RLS, authentication, database-side enforcement and an appropriate ballot-secrecy design.

See `docs/BUILD_GUIDE.md` and `sql/schema.sql`.
